# Sources

[1]: https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9 "NYC OpenData 311 Service Requests from 2020 to Present"

The project uses the official NYC OpenData 311 dataset, dataset ID `erm2-nwe9`. The source page states that the dataset is updated daily, represents service requests directed to specific agencies, contains no personally identifying information about requesters, and includes fields such as created date, closed date, agency, problem type, and geographic location.
