# Data

This project uses the official [NYC OpenData 311 Service Requests from 2020 to Present](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9) dataset, filtered to requests created from **2025-01-01 through 2025-03-31**.

- `sample/nyc311_q1_2025_sample.csv` contains the first 10,000 rows for quick inspection.
- The complete extract is generated locally by running `python src/download_data.py`.
- The full raw extract is approximately 213 MB and is intentionally excluded from GitHub by `.gitignore`.
- `data/processed/` is generated by `python src/analyze.py` and is also excluded from GitHub.

The source dataset is updated daily, so later downloads may produce updated closure timestamps. The exact query and selected fields are preserved in `src/download_data.py`.
